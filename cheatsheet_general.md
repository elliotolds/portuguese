- In real usage, _**seu/sua**_ can refer to ele(s)/ela(s)/você(s) but it's **overwhelmingly understood as "your (formal)"** in EP. Using it to mean "his/her/their" creates ambiguity, so speakers default to _**dele / dela / deles / delas**_ for those.

# demonstratives

| Distance                         | Masc       | Fem        | Neuter | + de                    | + em                    |
| -------------------------------- | ---------- | ---------- | ------ | ----------------------- | ----------------------- |
| near me (this)                   | este (s)   | esta (s)   | isto   | deste/desta/disto       | neste/nesta/nisto       |
| near you / just mentioned (that) | esse (s)   | essa (s)   | isso   | desse/dessa/disso       | nesse/nessa/nisso       |
| far from both (that over there)  | aquele (s) | aquela (s) | aquilo | daquele/daquela/daquilo | naquele/naquela/naquilo |

- The contractions above are _mandatory_.
- The neuter forms, _**isto**_ / _**isso**_ / _**aquilo**_, are used when:

- The noun is unknown or unspecified: _O que é isto?_ — What is this?
- Referring to abstract ideas: _Isso é verdade._ — That's true.
- Pointing without naming: _Quero aquilo!_ — I want that (over there)!

# question response words

| Word / Phrase       | Meaning                | Notes                                                          |
| ------------------- | ---------------------- | -------------------------------------------------------------- |
| sim                 | yes                    | But native EP often echoes the verb instead: _Vais? — Vou._    |
| não                 | no / not               | Also the negation word before any verb: _não tenho_, _não vou_ |
| está bem            | ok / fine              | The standard EP "ok" — natural in any register                 |
| obrigado / obrigada | thank you              | Agrees with the speaker's gender                               |
| claro               | of course              | Strong agreement                                               |
| pois                | right / indeed         | Very common EP filler for acknowledgment                       |
| pois é              | yeah, that's right     | Common chunk for agreeing                                      |
| talvez              | maybe                  | Pair with simple statements at A2: _talvez sim_, _talvez não_  |
| provavelmente       | probably               | _Provavelmente sim / não / vou / não vou_                      |
| acho que sim        | I think so             | High-value softer "yes"                                        |
| acho que não        | I don't think so       | High-value softer "no"                                         |
| claro que sim       | of course (yes)        | Strong affirmative                                             |
| claro que não       | of course not          | Strong negative                                                |
| espero que sim      | I hope so              | Common standalone reply                                        |
| espero que não      | I hope not             | Common standalone reply                                        |
| ok                  | ok                     | English borrowing; _está bem_ is more native                   |
| pois não            | no (soft disagreement) | Idiomatic EP — "no, you're right not to"                       |

- EP rarely answers with _sim_ alone. Native EP speakers more often **echo the verb** of the question:
  - _Vais ao café?_ — _Vou._ (instead of _sim_)
  - _Tens fome?_ — _Tenho._ (instead of _sim_)
